# Superstore Sales Analysis & Prediction

An end-to-end Exploratory Data Analysis (EDA) and Machine Learning project analyzing retail sales data from the Superstore dataset to uncover seasonal trends, performance metrics, and forecast sales.

---

## 📌 Project Overview
* **Data Cleaning & Preprocessing:** Handled missing values, removed duplicates, and parsed date features (`Order Date`, `Ship Date`, `Year`, `Month`, `Month_Year`).
* **Exploratory Data Analysis (EDA):** Analyzed monthly sales trends, seasonality, and product performance over time.
* **Predictive Modeling:** Trained a regression model using Scikit-Learn to predict sales figures and evaluated performance against actual values.

---

## 📁 Repository Structure
* `SQrock_Task_1.ipynb`: Google Colab / Jupyter Notebook containing the full code, visualizations, and modeling steps.
* `Superstore.csv`: The dataset containing transactional retail data.
* `README.md`: Project documentation and setup instructions.
